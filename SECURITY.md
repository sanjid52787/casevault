# Security policy

CaseVault is a fictional academic project and must only be used with synthetic data and inert evidence files.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Contact the project maintainer privately with a description, affected version or commit, reproduction steps, impact, and suggested mitigation. Acknowledgement is targeted within five working days. Reports will be assessed, remediated where practical, and credited only with the reporter's consent.

No production service, real client data, or third-party system is in scope. Do not conduct testing outside a local, authorised, isolated environment.
